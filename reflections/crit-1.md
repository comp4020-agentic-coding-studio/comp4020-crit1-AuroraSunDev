1. What was the breakthrough that moved the work forward?

   When I first started this project, I was not familiar with the agent workflow. I did not know how to use an agent efficiently or how much detail I needed to include in my prompts. After trying it for a while, I began to understand the basic process. The skills provided by COMP4020 were especially helpful. They allowed the agent to check the course requirements, understand the task, edit the project files, and run tests. Once I understood how to use these skills, the project became much clearer. I moved from feeling confused to completing most of the work through a few simple steps. The main breakthrough was learning how to guide the agent and use the available tools instead of trying to do everything manually.

2. ------

   What did this work change about who I want to be as a software developer?

   Before the rise of AI, I built a website by myself. It took a lot of time because I had to create and adjust every element step by step. Crit 1 gave me a much smoother experience. I only needed to describe my idea, and the agent created a working website within a few minutes. However, I also noticed that some parts met the course requirements but still did not look good to a human viewer. This made me realise that AI agents should improve development efficiency, but developers must still make decisions, review the results, and take final responsibility for the product.
